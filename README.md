A personal portfolio website showing my projects, about me, skills, and contact info

## 📁 Project structure

- `index.html` – main HTML page  
- `style.css` – styles for the page  
- `Images/` – assets used in the site

## 🚀 Getting started

You don’t need to build anything – just open `index.html` in a browser.  
(Optional: “or run a simple HTTP server with `python -m http.server` if you prefer.”)

## ✏️ How to modify

1. Edit `index.html` to change content.
2. Update `style.css` for styling.
3. Add/remove images in `Images/`.

## 🧰 Technologies

- HTML
- CSS
- JavaScript
